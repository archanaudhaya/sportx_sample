# 🏆 SportX – Sports E-Commerce Website

**SportX** is a modern and responsive sports e-commerce frontend designed to provide users with a smooth and engaging online shopping experience for sports products and equipment.

The project focuses on a clean UI, responsive design, product browsing, category navigation, and an intuitive shopping experience.

## 🚀 Features

* 📱 Fully responsive design for mobile, tablet, and desktop
* 🏠 Modern home page with hero section
* 🛍️ Sports product listing
* 🔎 Product search functionality
* 🏷️ Product categories and filters
* ⭐ Product ratings and reviews
* ❤️ Wishlist interface
* 🛒 Shopping cart interface
* 📦 Product details page
* 🔐 Login/Register UI
* 📞 Contact page
* ℹ️ About SportX section
* 🎨 Modern UI with hover effects and animations
* 📱 Mobile-friendly navigation
* ♻️ Reusable React components

## 💻 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/sportx.git
```

### 2. Open the Project

```bash
cd sportx
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will run locally using the development server.

SportX is designed using a mobile-first approach and adapts to:

* 📱 Mobile phones
* 📲 Tablets
